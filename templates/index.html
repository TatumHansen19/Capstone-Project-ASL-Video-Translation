ASL Alphabet Translator

This real-time ASL translator detects and interprets hand gestures into letters using computer vision and machine learning. It supports all static letters (A–Y) and motion-based signs (J and Z), offering both visual and audio feedback.

Features

  • Live webcam hand detection
  • Supports ASL A–Z (static & motion)
  • Confidence-based filtering
  • Text-to-speech output
  • Dynamic gesture detection for "J" & "Z"

Tools & Technologies

  • Python, OpenCV, MediaPipe
  • TensorFlow/Keras
  • Flask + Socket.IO
  • gTTS (text-to-speech)
  • HTML/CSS + JavaScript

Model Types

  • DNN for static letters (A–Y)
  • LSTM for motion letters (J, Z)
  • Separate training & prediction logic
  • Trained on real user gestures

Workflow

  1. Collect ASL gesture images
  2. Preprocess with MediaPipe
  3. Train static & dynamic models
  4. Predict & speak letters live

Built with accessibility, real-time responsiveness, and education in mind. Try signing a letter in front of your webcam to see it in action!
