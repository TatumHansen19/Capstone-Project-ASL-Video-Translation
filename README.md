# Capstone-Project-ASL-Video-Translation
Tatum Hansen and Yulissa Valencia. This is our repository for the capstone project.

The ASL Translator is a real-time American Sign Language Alphabet recognition tool designed to detect and translate ASL letters from a live video feed. It supports both static gestures (A–Y) using a CNN model and dynamic motions (J and Z) through a CNN+RNN (LSTM) hybrid approach. The program leverages TensorFlow, OpenCV, and MediaPipe for fast and accurate hand tracking and classification, with optional voice output using gTTS. To use the program, clone the repository, install the required packages, and run the application. A webcam feed will open, allowing users to sign letters, with predictions displayed and optionally spoken aloud. It is important to ensure that the application’s port number remains consistent (if using the web version) and that file paths to models and class labels are correctly configured before running. The ASL Translator was developed as part of a senior capstone project at Grand Canyon University and is intended to demonstrate real-time AI-driven gesture recognition for accessibility and communication enhancement.
